# Acceptance Entry Points

This index maps the requirements in `full-delivery-matrix.md` to real controls, protocol operations and evidence sources. It is a coverage map, not a declaration that final acceptance has passed. The matrix retains integration and scope decisions that are still open. MCP command names replace domain-command dots with underscores and preserve hyphens and case: `actor.joint-key.set` becomes `actor_joint-key_set`. All editing commands are also accepted by the atomic `edit_batch` tool. In the MCP column, names containing `*` are family patterns, not callable tool names; all other tool names are written in full. `tools/list` is a protocol method, not a tool.

Its separate engineering, performance and overall acceptance are tracked in the matrix.
